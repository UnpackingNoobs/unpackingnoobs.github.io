This is a collection of some special terms and abbreviations that you might find in one of the lections, if you've forgot what they mean, you can look them up here.

| Term        | Meaning          |
|:-------------|:------------------|
| Entry Point | The address of the first instruction that is executed when a program starts |
| EP | see _Entry Point_ |
| IAT | see _Import Address Table_ |
| Import Address Table | tbd |
| OEP | see _Original Entry Point_ |
| Original Entry Point | After the unpacking is done, this address is called, it's usually the Entry Point of the Original (unpacked) program, hence the name |
| packer stub | The routine that unpacks the original program |
| Relative Virtual Address | The address of an object once it is loaded in memory, minus the base address of the file image, or on other words, an offset to the base address. |
| RVA | see _Relative Virtual Address_ |
| stub | see _packer stub_ |
